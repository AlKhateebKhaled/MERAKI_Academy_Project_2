## 🧐 About <a name = "about"></a>

The **Movies App** is a dynamic single-page application (SPA) that allows users to explore and interact with a collection of movies. Users can search for movies, filter them by criteria such as duration, release year, and rating, and toggle between light and dark modes. The app also allows users to add movies to their favorites or watchlist. It supports both guest users and registered users with login functionality.
